테니스 복식 대진 모바일 PWA v1

[주요 기능]
- 참가자 4~16명
- 저장 참가자 DB / 원하는 참가자 선택 불러오기
- 남/여, 실력 1~5
- 파트너 변경 / 고정 파트너
- 남복/혼복/여복 경기 수 지정
- 코트별 허용 경기 종류 복수 선택
  예: 1코트=남복+혼복, 2코트=여복
- 코트별 대진표
- 개인 경기 수/실력 균형 및 파트너/상대 중복 최소화
- 무승부 점수 입력 및 승/무/패 순위
- 참가자 명단 JSON 내보내기/가져오기
- 브라우저 LocalStorage에 참가자 저장
- PWA 설치 및 오프라인 캐시 지원

[휴대폰에서 사용하는 가장 쉬운 방법]
이 폴더는 정적 웹앱입니다. GitHub Pages, Netlify, Cloudflare Pages 등 HTTPS 정적 호스팅에 올린 뒤 휴대폰에서 주소를 열면 됩니다.

Android Chrome: 메뉴 > 홈 화면에 추가 / 앱 설치
아이폰 Safari: 공유 버튼 > 홈 화면에 추가

주의: index.html 파일을 휴대폰에서 직접 여는 방식(file://)은 브라우저 제약으로 PWA 설치/서비스워커가 동작하지 않을 수 있습니다. HTTPS 주소로 여는 것을 권장합니다.

[PC에서 같은 Wi-Fi의 휴대폰으로 테스트]
1. 이 폴더에서 run_local_server.bat 실행
2. Windows 방화벽 허용
3. PC의 로컬 IP를 확인한 뒤 휴대폰 브라우저에서 http://PC_IP:8080 접속
   예: http://192.168.0.10:8080
※ 이 방식은 테스트용입니다. PWA 설치는 HTTPS 호스팅을 권장합니다.


v3 공유 화면 개선:
- 대진표의 공유용 한 화면 버튼 추가
- 코트별 대진을 1~2열의 압축 레이아웃으로 표시
- 점수 입력 UI를 제외해 아이폰 한 화면 스크린샷에 최적화
- 스크린샷 준비 버튼으로 조작 버튼 숨김
- 완료된 경기 점수는 공유 화면에도 표시
